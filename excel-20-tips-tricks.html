What You’ll Learn

Small actions that create a faster Excel workflow.

The masterclass starts with simple everyday improvements, then moves into stronger worksheet control and hidden productivity tools.

01

Enter & find information faster

Use Drop-Down Lists, AutoFill, Find, current date and current time shortcuts to reduce repeated entry.

02

Handle long worksheets confidently

Freeze headings, fill formulas quickly, sort with multiple levels, split windows, and hide information temporarily.

03

Make your worksheet respond to you

Use linked cells, AutoSum, Conditional Formatting, protected sheets, and fixed references to build smarter behaviour.

04

Discover Excel’s hidden gems

Monitor important cells with Watch Window and create a live linked picture using the Camera Tool.

All 20 skills, explained in one premium page.

01SKILL 01 OF 20

Create a Drop-Down List

Replace repeated typing with a controlled list of choices such as Paid, Partly Paid, or Not Paid.

Shortcut / CommandData → Data Validation → List
Practical Use

Use it for payment status, attendance, task status, stock status, or any field where the same answers repeat.

Back to top ↑
02SKILL 02 OF 20

Drag Dates, Months, Days & Number Patterns Automatically

Give Excel the beginning of a pattern, then drag the Fill Handle so Excel continues months, days, dates, or number sequences for you.

Shortcut / CommandFill Handle
Practical Use

Build schedules, calendars, serial numbers, date columns, and repeating patterns without typing every value.

Back to top ↑
03SKILL 03 OF 20

Find Information Quickly with Ctrl + F

Open Find, type the product name, code, number, or other value you need, then let Excel jump directly to it.

Shortcut / CommandCtrl + F
Practical Use

Search long worksheets quickly instead of scanning hundreds or thousands of rows manually.

Back to top ↑
04SKILL 04 OF 20

Double-Click the Fill Handle for Long Tables

After writing the first formula, double-click the Fill Handle to copy it down the connected table automatically.

Shortcut / CommandDouble-click the Fill Handle
Practical Use

Fill formulas through long sales, marks, inventory, or transaction tables without dragging through every row.

Back to top ↑
05SKILL 05 OF 20

Link Cells Quickly Using =

Create a connection to another cell instead of retyping its value. When the source changes, the linked cell follows.

Shortcut / Command= then click the source cell
Practical Use

Keep summaries, reports, dashboards, and repeated values connected to one original source.

Back to top ↑
06SKILL 06 OF 20

Insert the Current Date with Ctrl + ;

Insert today’s date instantly into the selected cell. This creates a fixed date, not a date that changes automatically.

Shortcut / CommandCtrl + ;
Practical Use

Record transactions, attendance, expenses, tasks, and other entries that need the date they were created.

Back to top ↑
07SKILL 07 OF 20

Freeze Headings While Scrolling

Keep your headings visible while moving through a long worksheet so the meaning of each column stays clear.

Shortcut / CommandView → Freeze Panes → Freeze Panes
Practical Use

Use it in marksheets, sales reports, inventory lists, and any table where the header disappears as you scroll.

Back to top ↑
08SKILL 08 OF 20

Use AutoSum with Alt + =

Let Excel calculate totals quickly. With the right selection, AutoSum can calculate horizontal and vertical totals in one move.

Shortcut / CommandAlt + =
Practical Use

Speed up weekly sales totals, subject totals, expense summaries, and other repeated addition tasks.

Back to top ↑
09SKILL 09 OF 20

Color Cells Containing Specific Text with Conditional Formatting

Tell Excel to highlight cells automatically when they contain important text, such as Low Stock.

Shortcut / CommandConditional Formatting → Text that Contains
Practical Use

Bring urgent information to your attention automatically instead of manually colouring cells.

Back to top ↑
10SKILL 10 OF 20

Hide and Unhide Rows or Columns

Temporarily remove rows or columns from view without deleting the information. Select the surrounding rows or columns and choose Unhide to bring them back.

Shortcut / CommandCtrl + 0 for columns · Ctrl + 9 for rows
Practical Use

Create a cleaner working or presentation view while keeping all original data available.

Back to top ↑
11SKILL 11 OF 20

Insert or Delete Rows and Columns with Keyboard Shortcuts

Insert a new selected row or column with Ctrl + Shift + Plus, then remove selected rows or columns with Ctrl + Minus.

Shortcut / CommandCtrl + Shift + + · Ctrl + -
Practical Use

Restructure tables quickly when new records, categories, or layout changes are needed.

Back to top ↑
12SKILL 12 OF 20

Create a Copy of a Worksheet to Keep the Original

Duplicate a worksheet with its data, formulas, and formatting before you make major changes.

Shortcut / CommandHold Ctrl + drag the worksheet tab
Practical Use

Keep a safe original before experimenting with reports, formulas, designs, or monthly updates.

Back to top ↑
13SKILL 13 OF 20

Transpose with Paste Special

Turn data arranged across rows into columns, or columns into rows, without retyping it.

Shortcut / CommandCopy → Paste Special → Transpose
Practical Use

Reorganise data when the original direction is inconvenient for a report, chart, or analysis.

Back to top ↑
14SKILL 14 OF 20

Insert the Current Time with Ctrl + Shift + ;

Insert the current time instantly into the selected cell. Like the date shortcut, this creates a fixed time.

Shortcut / CommandCtrl + Shift + ;
Practical Use

Record visitor arrival, attendance, task completion, or other time-based entries accurately and quickly.

Back to top ↑
15SKILL 15 OF 20

Custom Sort with Multiple Levels

Sort a table by one field first, then add another level. In the lesson, records are grouped by Purpose and then arranged by Time In.

Shortcut / CommandData → Sort → Add Level
Practical Use

Organise detailed records when one simple A-to-Z sort is not enough.

Back to top ↑
16SKILL 16 OF 20

Lock Cell References Quickly with F4

Select a reference inside a formula and press F4 to lock it with dollar signs. Press F4 again to cycle through the locking combinations.

Shortcut / CommandF4 · some laptops: Fn + F4
Practical Use

Keep one rate, target, tax, discount, or other fixed cell constant while copying formulas down a table.

Back to top ↑
17SKILL 17 OF 20

Split the Worksheet Window

Divide one worksheet window into separate sections so you can view one area while scrolling another.

Shortcut / CommandView → Split
Practical Use

Compare records far apart in the same worksheet without constantly scrolling back and forth.

Back to top ↑
18SKILL 18 OF 20

Protect a Worksheet

Prevent unwanted changes to protected cells and optionally require a password before the sheet can be unprotected.

Shortcut / CommandReview → Protect Sheet
Practical Use

Protect finished reports or result sheets from accidental editing. It is for editing control, not high-security confidential data.

Back to top ↑
19SKILL 19 OF 20

Monitor Important Cells with Watch Window

Add an important cell to Watch Window so you can see its value update even when you are working far away in the worksheet.

Shortcut / CommandFormulas → Watch Window → Add Watch
Practical Use

Monitor a Grand Total or key formula while changing data elsewhere without repeatedly scrolling back to it.

Back to top ↑
20SKILL 20 OF 20

Create a Live Picture with the Camera Tool

Select a cell range, use the Camera Tool, then place the linked picture elsewhere. When the original cells change, the picture updates too.

Shortcut / CommandQuick Access Toolbar → Camera
Practical Use

Create live summaries, dashboard elements, or repeated report views without rebuilding the same information.
