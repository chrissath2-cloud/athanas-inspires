# Add a Lesson

1. Open `templates/NEW-LESSON`.
2. Copy `lesson.json` into the correct series folder, for example `source/content/lessons/excel-series/lessons`.
3. Rename it using a short unique ID, for example `excel-6.json`.
4. Replace every placeholder. JSON requires quotation marks around text and commas between properties.
5. Add the new ID to that series’ `lesson-order.json` in the position where it should appear.
6. Place related downloads in `source/public/assets/downloads`, or keep a clearly named lesson asset folder.
7. Double-click `UPDATE WEBSITE.bat` and inspect Courses, YouTube, search, and related assignments.
