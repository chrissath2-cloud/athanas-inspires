# First-Time Setup

1. Install the current **Node.js LTS** version from the official Node.js website. Node.js is the free program that prepares the finished website.
2. Extract this project into a normal folder on your laptop.
3. Double-click `SET UP WEBSITE.bat`. This downloads the project building tools into `node_modules`.
4. Double-click `UPDATE WEBSITE.bat`.
5. Open `website/index.html`, or use `OPEN WEBSITE.bat` for complete testing.

You do not type commands for the normal process; the `.bat` files perform them.
