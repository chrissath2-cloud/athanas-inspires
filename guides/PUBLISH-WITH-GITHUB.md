# Publish with GitHub Pages

1. Rebuild and preview locally.
2. Upload or push the complete project to the GitHub repository.
3. In GitHub, open **Settings → Pages** and select **GitHub Actions** as the source.
4. The included workflow builds from `source`, runs checks, and publishes `website`.
5. Do not upload `README-PRIVATE-PAGE.txt`; it was intentionally removed because public repositories must never contain private passwords.
